Supabase → проект → SQL Editor → вставьте и запустите. Затем Settings → API: скопируйте Project URL и публичный ключ сюда → «Подключить». Данные у вас зашифрованы, поэтому открытая RLS-политика безопасна.

Пароль и шифрование

Пароль — это ключ шифрования. При смене данные заново шифруются новым паролем и сохраняются в облако. Новый пароль восстановить нельзя — запишите его. Со следующего входа (на всех устройствах) — только новый пароль.

Восстановление по почтенет кода

Создай код восстановления и отправь его себе на почту. Если забудешь пароль — на входе нажмёшь «Забыли пароль?», введёшь код и задашь новый пароль. Данные останутся зашифрованными.

Цели накоплений

«Цель, млн Rp» — нужная сумма. Статус «по плану %» / «📋 план собран» — это сколько планируется отложить (из План/Факт). Фактически отложенное и «🎯 достигнута» считаются по конвертам (подвкладка «Реальный остаток»). «Закрыть» — пометить цель завершённой вручную (например, байк куплен): уйдёт вниз и здесь, и в «Накоплениях», история останется. Удаление (✕) стирает цель целиком.
